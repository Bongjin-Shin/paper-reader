Paper Vocabulary — Ubuntu 설치판
Ubuntu 24.04 이상 · Intel/AMD 64비트(amd64)

설치
1. .deb 파일을 저장한 폴더에서 터미널을 엽니다.
2. 아래 명령으로 설치합니다. 필요한 시스템 라이브러리도 함께 설치됩니다.
   sudo apt install ./PaperVocabulary-0.1.1-Ubuntu-amd64.deb
3. 앱 목록에서 Paper Vocabulary를 실행합니다.

.deb 파일을 소프트웨어 설치 앱으로 열어 설치할 수도 있습니다.
소프트웨어 설치 앱이 없거나 파일이 열리지 않으면 위 터미널 명령을 사용하세요.

AI 연결
- 번역 연결 설정에서 ChatGPT 구독 또는 Claude 구독을 선택하고 본인 계정으로 로그인합니다.
- ChatGPT 연결 도구는 이 설치 파일에 포함되어 있습니다. Node.js나 Rust를 설치할 필요가 없습니다.
- Claude는 “Claude 연결 도구 설치”를 눌러 처음 한 번 공식 연결 도구를 다운로드합니다.
- Claude 로그인은 기본 브라우저에서 진행합니다. 채팅창 아래에서 잔여 비율을 확인할 수 있습니다.
- 채팅의 공급자·모델·effort는 번역과 별도로 설정합니다.
- 의존성/연결 도구 다운로드와 로그인, 번역·채팅 호출에는 인터넷이 필요합니다.

개인 데이터와 업데이트
이 설치 파일에는 개발자의 논문, 단어장, 채팅 기록, 로그, API 키, 로그인 정보가 들어 있지 않습니다.
개인 기록은 각 사용자의 다음 폴더에 저장됩니다.
~/.local/share/com.papervocabulary.reader/PaperVocabulary
XDG_DATA_HOME을 따로 설정했다면 해당 경로 아래에 저장됩니다.
업데이트할 때는 기존 사용자 기록을 보존합니다.
앱 패키지를 제거하면 이 컴퓨터의 각 사용자 계정에 있는 앱 전용 데이터도 자동 삭제합니다.
기존 AppImage 바로가기는 별도로 남을 수 있습니다. DEB 설치판은 앱 목록에서 실행하세요.

삭제
1. Paper Vocabulary와 연결 도구를 완전히 종료합니다.
2. Ubuntu 소프트웨어 앱에서 제거하거나 다음 명령을 실행합니다.
  sudo apt remove paper-vocabulary
3. 패키지 제거 후 논문 사본, 단어장, 채팅, 로그인 정보, 앱 설정과 캐시를 자동 삭제합니다.
   별도의 데이터 삭제 선택 창은 없으며 apt purge도 동일하게 처리합니다.

기본 삭제 대상은 각 사용자 홈 아래의 다음 앱 전용 폴더입니다.
  ~/.local/share/com.papervocabulary.reader
  ~/.config/com.papervocabulary.reader
  ~/.cache/com.papervocabulary.reader
이 버전 실행 시 등록한 사용자 지정 XDG 데이터·설정·캐시 경로도 함께 정리합니다.
접근할 수 없는 홈 또는 이전 버전에서만 사용한 미등록 사용자 지정 경로는 별도로 정리해야 합니다.
앱 밖에 있는 원본 PDF와 다른 앱 데이터는 삭제하지 않습니다.
같은 데이터 폴더를 사용하는 AppImage·개발 버전의 기록도 함께 삭제됩니다.
재설치해도 삭제한 기록은 복구되지 않으므로 필요한 자료는 제거 전에 앱 밖에 백업하세요.
업데이트(새 DEB 덮어 설치) 시에는 기록을 보존합니다. 기존 AppImage 설치 파일·바로가기는 별도로 남습니다.

버전: 0.1.1
