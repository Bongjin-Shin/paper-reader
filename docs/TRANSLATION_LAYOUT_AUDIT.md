# 번역 구조 점검 · 2026-10-22

## 확인 및 수정

- Library의 논문 26편, 438페이지를 PDF.js로 추출하고 수정 전후 텍스트를 대조했다. 모든 논문의 첫 페이지와 알고리즘·표·수식·원고 페이지를 포함한 55페이지는 렌더링한 원본도 확인했다.
- 번호가 붙은 알고리즘 박스, 테두리 없이 아래에 캡션을 둔 의사코드를 번역 대상에서 제외했다. 알고리즘 참조와 설명 본문은 유지한다.
- 알고리즘이나 표를 제외한 뒤에도 원래 단의 구분을 유지한다. 한쪽 단 대부분이 알고리즘인 페이지에서 남은 소제목이 반대편 본문에 붙던 사례를 회귀 테스트로 추가했다.
- 부록 표 번호와 긴 표의 아래 테두리를 인식하여 표 안의 값이 본문에 섞이지 않도록 보완했다.
- 내장 글꼴 로드 후 위치를 측정한다. 가까운 원고 줄 번호, 같은 글자 크기의 머리말·날짜 꼬리말, 마침표 없는 절 번호, 독립된 굵은 소제목을 보완했다. 번호로 시작하는 긴 일반 문장을 제목으로 분류하지 않는다.
- 수식 정보가 많은 문장도 분량에 맞게 분할한다. 수식 주변 본문이 전부 빠진 결과를 거부하고, 불완전한 모델 출력은 제한된 횟수 안에서 더 작은 구간으로 재시도한다. 전체 페이지 검증 후에만 저장한다.
- 채팅 입력은 줄 수에 따라 늘어나며 높이 상한 이후 내부 스크롤을 사용한다. 사용량 새로고침 버튼의 설명 툴팁을 제거했다.

## 검증 범위

- 438페이지, 원문 항목 19,624개에 실제 Rust 요청 검증을 실행하여 텍스트·수식·좌표 스키마 통과를 확인했다.
- 저장된 번역 86페이지의 문장 대응과 수식 토큰을 자동 점검했다. 모델을 새로 호출해 전체 논문을 재번역하지는 않았다.
- Ubuntu WebKit에서 부록 알고리즘, 수식, 원고, 페이지 꼬리말, 비대칭 단을 포함한 실제 PDF 5페이지를 확인했다. 최초/반복 추출이 일치하고 Chromium과 원문 단어가 같았다.
- Vitest 117개, Rust 132개, 관련 Playwright 28개 통과. 별도 로컬 corpus 검증도 통과했다. 모델 호출은 모의 응답을 사용했다.

이 검증은 읽는 순서·누락 방지·좌표·응답 처리에 대한 검사다. 모든 문장의 한국어 의미를 사람이 대조하거나 실제 모델의 번역 정확도를 평가한 것은 아니다. OCR 없는 이미지 PDF, 표준과 다른 의사코드 형식과 복잡한 다단 배치에는 추가 사례 검증이 필요하다. 기존 완료 번역은 보존하며, 변경된 추출 구조를 적용하려면 해당 페이지를 재번역한다.

실제 PDF, DB 사본, 추출 결과와 상세 로그는 Git에서 제외된 `.tools/library-translation-audit-qa/`에만 보관한다.
