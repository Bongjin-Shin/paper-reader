# 말풍선 유지·문서 위치·원문 선택 · 2026-09-29

## 변경 동작

- 각 선택의 말풍선을 독립적으로 관리합니다. 2026-09-30 보완: 동작 메뉴는 임시로 하나만 표시하고, 바깥 클릭·새 선택·화면 전환 시 닫습니다. 번역/설명을 실행한 이후의 로딩·결과·오류 말풍선만 바깥 클릭이나 다른 단어·문장 조회로 닫히지 않습니다. 각 말풍선의 X, 해당 말풍선 선택 후 Esc/Delete로만 닫습니다. 하이라이트 제거는 결과 말풍선을 닫지 않습니다.
- Library/Vocabulary 이동, 뒤로·앞으로 가기, 실행 취소도 이미 요청한 결과 말풍선을 닫지 않습니다. 다른 PDF를 열면 이전 논문의 말풍선을 숨기고 해당 논문으로 돌아올 때 복원합니다. 말풍선 UI 상태는 현재 앱 세션의 메모리에만 유지합니다. DB 스키마와 기존 저장 데이터는 바꾸지 않았습니다.
- 직접 옮긴 말풍선도 화면에 고정하지 않습니다. 놓은 지점을 PDF 페이지 번호와 배율 1의 페이지 좌표로 기록해 스크롤·줌·너비 맞춤·창 크기 변경 후에도 같은 문서 위치를 유지합니다. 스크롤하면 화면 밖으로 나가며 되돌아오면 다시 보입니다.
- 말풍선 클릭 시 선택 시작/끝 오프셋으로 원문의 네이티브 텍스트 선택 범위를 복원합니다. 같은 단어의 다른 위치를 구분하고 드래그·삼중클릭 문장도 지원합니다. 활성 말풍선만 맨 앞으로 올립니다. 영구 하이라이트나 단어장 기록을 추가하지 않습니다.
- 같은 더블/삼중클릭 제스처 중 잠시 만들어지는 중간 메뉴는 최종 선택으로 합칩니다. 이미 요청한 다른 결과는 교체하지 않습니다. 닫힌 말풍선은 늦은 응답으로 다시 열리지 않습니다.

## 구현과 성능

`App`의 단일 말풍선을 논문별 ID를 가진 목록으로 바꿨으며 요청 완료와 닫기를 ID별로 처리합니다. 비동기 응답, 재시도, 하이라이트 제거가 다른 말풍선을 덮어쓰지 않습니다.

`useBubblePosition`은 모든 말풍선을 문서 내 absolute 위치로 배치합니다. 스크롤 리스너는 추가하지 않았습니다. 드래그 중 해당 말풍선만 RAF로 위치를 갱신하고, 놓을 때 좌표를 저장합니다. 페이지 좌표 변환은 줌·리사이즈·배치 시에만 수행합니다. PDF canvas/Text Layer/Highlight Layer의 캐시·가상화와 본문 번역 경로는 유지합니다.

## 검증

새 E2E 테스트는 여러 말풍선과 개별 닫기, 비동기 요청과 화면 이동, 하이라이트 삭제·실행 취소, 문서 좌표와 양방향 스크롤·줌·리사이즈, 드래그·삼중클릭 선택 복원, 논문 전환, 동일 단어의 다른 위치 및 Text Layer 해제 후 복원을 확인합니다. 이전 테스트 중 새 요구와 달라진 화면 고정·자동 닫기 기대값을 수정했습니다.
