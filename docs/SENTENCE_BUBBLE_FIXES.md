# 굵은 본문·수식·말풍선 보정 · 2026-09-28

사용자가 보고한 두 논문의 로컬 사본으로 추출과 화면 표시를 재현했습니다. 원본 PDF와 사용자 DB를 수정하지 않았고, 실제 모델/유료 API는 호출하지 않았습니다.

## 문장 끊김

굵은 글씨라는 이유로 초록의 각 행을 제목으로 분류했습니다. 마침표로 끝나는 마지막 행은 본문으로 분류되어 하나의 문장이 둘로 나뉘었습니다. 글씨 굵기만으로 제목을 결정하지 않게 했으며 번호가 붙은 제목은 한 단위로 유지합니다. 작은 각주가 첨자로 오인되어 행 순서가 바뀌거나 다음 단으로 이어지는 본문 사이에 끼는 경우, 큰 첫 글자가 다음 행에 붙는 경우도 보정했습니다.

보고된 문장 `Comparison simulations … effectiveness of the proposed algorithm.`은 이제 전체 3줄이 하나의 ID와 세 개의 원문 위치로 추출됩니다. 한 단/두 단 합성 PDF와 실제 논문의 양방향 회색 표시로 확인했습니다.

## 수식 깨짐

`N_success`, `f_cost`의 작은 영문 아래첨자는 일반 본문 폰트여서 수식 중간의 번역 대상 본문으로 잘못 분류됐습니다. 여러 줄 조건식의 각 부분이 서로 다른 수식/본문 블록으로 잘리면서 큰 괄호·합계 기호가 조각나거나 중복 노출됐습니다.

작은 영문 아래첨자와 수학 함수·변수를 수식에 포함하며 행의 큰 기본 글자 크기를 기준으로 기준선을 묶습니다. 수식 내부 공백을 논문의 두 단 간격으로 오인하지 않도록 본문 행에서 단 간격을 판별합니다. 독립 수식 블록은 원본 전체 영역 이미지만 표시하며 모델의 추가 문구를 붙이지 않습니다. 보고된 `(1)`~`(3)` 식의 합계·조건식·첨자·식 번호가 한 이미지에 잘리지 않고 들어가는 것을 확인했습니다.

수식 인식은 PDF 텍스트/폰트/좌표에 기반하며 OCR이나 LaTeX 복원은 추가하지 않았습니다. 이미지 전용 수식이나 복잡한 도표의 기호에는 한계가 있습니다. 기존 수식 렌더 크기 제한과 페이지별 재사용은 유지합니다.

## 문장 말풍선

수정 전에는 단어·문장 모두 `position: fixed`로 표시하고 Reader의 scroll 이벤트에서 RAF로 화면 좌표를 보정했습니다. 직접 옮기지 않은 말풍선은 Reader의 문서 좌표 안에 `absolute`로 배치하도록 변경했습니다. 이제 스크롤 이벤트가 실행되기 전에도 PDF와 정확히 같은 거리로 이동하며 가장자리에서 멈추지 않습니다. 큰 결과와 양방향 선택, 응답 도착 중 스크롤을 포함합니다.

말풍선 내부 결과는 계속 스크롤해 읽을 수 있고, 끝까지 읽은 뒤에는 휠이 Reader 스크롤로 이어집니다. 클릭만으로 화면에 고정하지 않습니다. 직접 드래그한 말풍선은 기존처럼 옮긴 화면 위치에 고정합니다. X/Escape/Delete 닫기, 단어장/하이라이트 보존, 실패 재시도, 줌·너비 맞춤은 유지합니다.

## 캐시와 검증

SQLite schema v11은 유지하며 본문 추출 캐시 버전은 4입니다. 잘못 나뉜 v1~v3 결과는 다음 명시적 본문 번역에서 해당 페이지만 다시 만듭니다. 전체 논문 자동 호출이나 기존 Vocabulary/단어 API 캐시 삭제는 수행하지 않습니다.

자동 검증에 굵은 초록의 문장 끝, 작은 각주와 단 연결, 큰 첫 글자, 일반 폰트 아래첨자·다중 행 조건식, 긴 문장 말풍선의 동기 스크롤과 내부 스크롤 연결을 추가했습니다. 결과와 네이티브 화면은 `.tools/bold-sentence-bubble-verification/`에 보관합니다.

최종 검증: Vitest 66개, Rust 82개, Playwright 150개로 총 298개 통과했습니다. 기존 외부 Codex 런타임 수동 테스트 1개는 계속 제외합니다. Rust 포맷·Clippy, TypeScript, Tauri release 빌드와 AppImage/deb/rpm 번들을 확인했습니다. 초기 병렬 실행에서 테스트용 Codex 프로세스 시작이 한 번 실패했으며 Rust 전체를 직렬 재실행하여 통과했습니다.

AppImage와 바탕화면 실행 파일도 갱신했습니다. 격리 DB와 가짜 모델 응답을 쓰는 실제 WebKit 데스크톱 앱에서 긴 말풍선의 PDF 스크롤 이동, 내부 휠의 Reader 연결, 수동 드래그 후 위치 유지와 보고된 실제 논문의 수식 `(1)`~`(3)` 표시를 확인했습니다. 설치된 AppImage에서 새 본문 결과가 캐시 버전 4로 저장되는 것도 확인했습니다. 모델 응답 자체의 번역 품질은 유료 호출 없이 검증할 수 없어 이번 검증 범위에서 제외합니다.
