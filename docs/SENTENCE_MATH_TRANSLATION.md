# 문장 단위 번역·문단 정렬·수식 표시 · 2026-09-24

## 원인과 변경

기존 추출은 PDF의 글꼴별 선택 영역 높이와 줄 간격을 문단 경계의 단서로 사용했습니다. 긴 문장이 다음 줄의 이탤릭체, 첨자 또는 큰 줄 간격을 만나면 문단이 나뉘어 줄별 번역처럼 보일 수 있었습니다.

- 행 정렬은 폰트 기준선을 사용하고 작은 첨자·악센트를 가까운 본문 행에 붙입니다. 시각적인 행과 번역 단위를 분리해 끝나지 않은 문장은 다음 줄·다음 단까지 연결한 뒤 문장 부호로 분할합니다. 약어와 소수점은 문장 끝으로 오인하지 않도록 합니다. 제목, 독립 수식, 문단 구분은 유지합니다.
- 두 단 본문 중간에 끼던 하단 그림 캡션은 본문 다음으로 정리합니다. 실제 로컬 논문의 4페이지 단 경계 문장, 5페이지 정의 문장, 6페이지 여러 줄 문장이 하나의 번역 단위가 되는 것을 확인했습니다.
- 번역 문장을 문단으로 묶고 창 너비에 맞춰 자동 줄바꿈·양쪽 정렬합니다. 각 문장의 hover·클릭·키보드 조작과 회색 대응 음영은 유지합니다.
- 수식은 수학 폰트·기호와 위치로 인식합니다. 번역 요청에는 수식 자리표시자를 넣고 원본 영역 이미지를 번역문에 표시합니다. 이미지로 분수선·첨자·괄호를 보존합니다. 일부 수학 폰트의 과도한 선택 영역은 인접 본문 영역을 침범하지 않도록 제한합니다.
- 수식용 렌더링은 현재 번역 페이지에 한정하며 최대 400만 픽셀·2배 배율의 단일 Canvas를 공유합니다. 렌더는 프레임 사이에 양보하며 페이지 변경/패널 닫기에 취소·해제합니다. 이미지들은 같은 페이지의 hover·줌·번역창 크기 변경에 재사용합니다. 기존 Reader 렌더 큐·캐시·줌·선택 코드는 바꾸지 않았습니다.

기존 SQLite schema v11을 유지하며 `page_translations.layout_version`만 3으로 사용합니다. 이전 버전 캐시를 자동 삭제하거나 전체 문서를 자동 번역하지 않습니다. 다음 명시적 본문 번역에서 해당 페이지만 새 문장 구성으로 번역합니다. API/Codex 제공자, 모델, 요금, 스트리밍 방식은 유지합니다. 수식 자리표시자가 누락·중복된 응답은 최종 저장과 앱 내부 비용 기록에서 제외합니다.

## 검증

- 단위: 줄 간격·폰트 높이가 다른 긴 문장, 위첨자/이탤릭체, 단 경계 연결, 약어/소수점, 수식과 주변 본문 분리, 수식 이미지 경계.
- 브라우저: 세 줄 문장을 한 ID로 요청, 두 단을 잇는 문장, 좁고 넓은 번역창의 정렬/줄바꿈, 분수선과 위첨자 표시, 회전 PDF의 수식, 양방향 음영, 이미지 재사용, 재실행 후 캐시 재사용.
- Rust: 문단·수식 좌표 메타데이터 저장/재실행, 요청에서 좌표 제외, 수식 자리표시자 누락·중복 및 잘못된 좌표 거절, 이전 레이아웃 캐시의 명시적 갱신.
- 기존 Reader/Library/Vocabulary/선택/하이라이트/출력/undo/redo/설명 캐시/스트리밍 회귀 시나리오를 유지합니다.

실제 로컬 두 단 논문과 합성 한 단 PDF를 화면으로 확인했습니다. 합성 PDF는 분수선·위첨자·회전과 넓어진 줄 간격을 포함합니다. 실제 논문에서 악센트와 큰 합집합 기호의 선택 영역에 섞이던 윗줄 조각도 제거되는 것을 확인했습니다. 본문에 이미 포함된 색상은 원본 수식 이미지에도 남을 수 있습니다.

실제 유료 API/구독 모델은 호출하지 않았습니다. 모델 번역 품질·응답 시간은 측정하지 않았으며 모의 응답으로 요청 구성·스트리밍·저장·UI를 검증합니다. OCR은 추가하지 않았습니다. 이미지 전용 수식, 복잡한 표/세 단 이상, 비표준 글리프 배치, PDF 텍스트 항목에 섞인 첨자는 자동 인식에 한계가 있습니다. 수식은 편집 가능한 LaTeX가 아닌 원본 이미지입니다.

검증 로그·화면은 `.tools/sentence-math-verification/`에 보관합니다.

자동 검증은 Vitest 62개, Rust 82개, Playwright 143개, 총 **287개 통과**입니다. 기존 외부 인증 수동 테스트 1개는 제외했습니다. 전체 브라우저 테스트 통과 뒤 최종 수식 경계 보정에 대해 본문 번역 관련 21개를 다시 통과했습니다. `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, Tauri release 빌드 및 AppImage/deb/rpm 패키징을 통과했습니다.

네이티브 앱은 격리된 테스트 DB와 모의 Codex로 확인했습니다. 3줄 원문이 하나의 문장으로 요청·저장되고 해당 3줄과 한글 번역 한 문장이 함께 회색으로 표시됩니다. 분수·위첨자 수식 표시와 패널 너비 조절/너비 맞춤도 확인했습니다. 본문 번역 후 Vocabulary·Context·Highlight는 각각 0개이며 기존 분리 정책을 유지합니다. 사용자 DB는 검증에 사용하지 않았습니다.

설치본도 갱신했습니다. 설치된 AppImage를 같은 격리 DB로 재실행한 뒤 문장·문단·수식 이미지·번역창 너비가 복원됐고, 모의 모델 호출 수는 최초 1회로 유지됐습니다.
