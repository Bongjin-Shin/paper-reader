# Paper Vocabulary

**영문 논문을 읽고, 번역하고, 질문하며 나만의 단어장을 만드는 데스크톱 앱입니다.**

PDF 원문과 한국어 번역을 나란히 보면서 논문을 읽을 수 있습니다. 모르는 단어는 선택해서 뜻을 확인하고, 이해하기 어려운 내용은 AI에게 질문하세요. 읽던 논문과 메모, 단어장, 채팅 기록을 한곳에서 관리할 수 있습니다.

Windows와 Ubuntu용으로 개발하고 있습니다.

설치 파일은 [GitHub Releases](https://github.com/Bongjin-Shin/paper-reader/releases)의 **Assets**에서 내려받을 수 있습니다. Windows는 `.exe`, Ubuntu는 `.deb` 파일을 선택하세요.

## 주요 기능

- **원문 옆 페이지 번역** — 각 PDF 페이지 옆에 한국어 번역을 표시합니다. 필요한 페이지를 직접 번역하고, 진행 중에도 중단하거나 재번역할 수 있습니다.
- **선택한 부분 번역·설명** — 단어나 문장을 선택해 해당 문장의 맥락을 고려한 번역과 설명을 확인하거나 AI 질문에 첨부합니다. 번역과 대응하는 원문을 음영과 연결선으로 확인할 수 있습니다.
- **논문 AI 채팅** — 논문 내용을 바탕으로 질문하고 답변을 받습니다. 이전 질문 수정과 대화 버전 전환을 지원하며, 번역과 채팅의 AI 제공자·모델·추론 수준(effort)을 각각 설정할 수 있습니다.
- **문서 구조와 수식 표시** — 제목·문단을 구분하고 Markdown과 LaTeX 수식을 렌더링합니다. 그림·표의 캡션은 별도 영역에 표시합니다.
- **논문 라이브러리** — 폴더, 중요도, 메모로 논문을 정리하고 제목·저자·날짜 등으로 정렬합니다. 마지막 정렬 설정은 앱을 다시 실행해도 유지됩니다.
- **개인 단어장** — 선택해서 번역한 단어와 구·문장을 자동으로 저장합니다. 검색, 논문별 필터, PDF 내보내기를 지원합니다.
- **읽기 도구** — 본문 검색(`Ctrl+F`), 확대·축소(`Ctrl++` / `Ctrl+-`, `Ctrl+0`으로 초기화), 너비 맞춤, 여러 색의 하이라이트, 실행 취소·다시 실행을 제공합니다. 번역창과 채팅창은 각각 너비와 글자 크기를 조절할 수 있으며, 설정은 앱을 다시 열어도 유지됩니다.

## 시작하기

1. 배포받은 Windows 설치 파일(`.exe`) 또는 Ubuntu 설치 파일(`.deb`)로 앱을 설치합니다.
2. **Library → PDF 추가**를 누르거나 PDF를 앱 창에 드래그합니다.
3. **번역 연결**에서 ChatGPT 구독 또는 Claude 구독을 선택하고 본인 계정으로 로그인합니다. Claude는 처음 연결할 때 앱에서 연결 도구를 설치합니다.
4. 단어·문장을 선택해 **번역 / 설명 / AI질문**을 사용하거나, **본문 번역 → 이 페이지 번역**으로 페이지를 번역합니다.

설치 환경과 자세한 절차는 [Windows 안내](docs/WINDOWS_DISTRIBUTION.md)와 [Ubuntu 안내](packaging/ubuntu/설치안내.txt)를 참고하세요. 설치판 실행에는 Node.js나 Rust가 필요하지 않습니다.

> Ubuntu DEB 설치판은 앱을 제거할 때 앱에 저장된 기록도 삭제합니다. 필요한 기록은 제거 전에 백업하세요. 업데이트 설치 시에는 기록을 유지합니다.

## AI 연결과 데이터

ChatGPT·Claude 구독 연결은 공식 CLI를 통해 사용하며 해당 계정의 사용 한도가 적용됩니다. 사용할 수 있는 모델과 effort는 연결한 계정·모델에 따라 달라집니다. 번역에는 OpenAI API 키를 사용하는 방식도 제공하며, API 사용료는 구독과 별도입니다.

논문 사본, 메모, 단어장, 하이라이트와 채팅 기록은 내 컴퓨터에 저장합니다. AI 번역·채팅을 요청할 때는 작업에 필요한 원문과 대화 문맥을 선택한 AI 제공자에게 전송하므로 인터넷 연결이 필요합니다. PDF 읽기와 저장된 기록 열람은 AI 연결 없이 사용할 수 있습니다.

텍스트를 선택할 수 있는 PDF를 대상으로 합니다. 스캔 문서의 OCR은 지원하지 않으며, 복잡한 수식이나 다단 편집 문서는 추출·번역 결과를 원문과 비교해 확인하는 것이 좋습니다.

## 소스에서 실행하기

기술 구성은 **Tauri 2 · React · TypeScript · Rust · PDF.js · SQLite**입니다.

Node.js **22.13 이상**, Rust **1.88 이상**, 운영체제별 Tauri 개발 의존성을 준비한 뒤 프로젝트 폴더에서 실행합니다. 자세한 준비 과정은 [개발 환경 안내](docs/IMPLEMENTATION_NOTES.md#개발-실행)를 참고하세요.

```bash
npm ci
npm run tauri dev
```

구독 연결은 앱에서 로그인하면 됩니다. OpenAI API 방식을 사용할 때만 `.env.example`을 `.env`로 복사하고 `OPENAI_API_KEY`를 설정하세요. 개인 키가 들어 있는 `.env`는 Git에 올리지 않습니다.
